# Data Cleaning & Reporting Automation

**Thiranex Data Analytics Internship — Task 4**

## Objective
Automate data cleaning, quality checking and reporting using the Superstore dataset.

## Cleaning workflow
- Removed exact duplicate rows
- Trimmed whitespace from text fields
- Standardized capitalization for names, locations and categories
- Converted Order Date and Ship Date to valid dates
- Converted Sales, Quantity, Discount and Profit to numeric values
- Handled missing numeric values with median imputation
- Handled missing categorical/date values with controlled replacements
- Created a quality report comparing missing values before and after cleaning
- Created a summary report with business KPIs

## Results
- Raw rows: 9,994
- Cleaned rows: 9,994
- Exact duplicates removed: 0
- Missing cells before: 0
- Missing cells after: 0
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Quantity: 37,873
- Distinct Orders: 5,009
- Distinct Customers: 793
